# Non-Game Learning Hub

This folder is the home for non-game learning.

## Scope

- Keep non-game learning content here.

## Goal

Build durable skill, not just platform progress.

## Default Workflow

1. Capture notes on paper during study sessions.
2. Distill only high-value takeaways into digital notes.
3. Build at least one from-memory exercise per module.
4. Do weekly review and update summaries.

## Folder Conventions

- Python/Udemy/<CourseName>/
- C++/Content/<Topic>/
- CheatSheets/<LanguageOrTool>/

Per-course recommended files:

- NOTES.md
- Scratch/
- SUMMARY.md

## Course Access Policy

- Use work-sponsored access for exploration.
- Buy on personal account only for long-term keepers.
- Keep your own notes and code so learning survives account changes.

## Maintenance Rule

- If a file does not help recall, reuse, or execution, archive it.
