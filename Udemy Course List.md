# Udemy Course List - Recommended Order

This order is optimized for your current priorities:
- Primary: Game development (Unity first)
- Secondary: Unreal cross-training later
- Tertiary: Non-game Python/web stack

Legend:
- [DO] = full course
- [SKIM] = move fast, fill gaps only
- [OPTIONAL] = useful but not required now
- [LATER] = postpone until a later phase
- [DEFER] = postpone until priorities are complete
- [REFERENCE] = keep as a lookup/resource course, not a linear watch
- [ToBuy] = in corporate list but not in personal library yet
- [REFRESHER] = short textbook review checkpoint tied to prior college course texts

## Foundation rules

1. Do not run more than 1 core course at a time.
2. Pair each core course with one small from-memory build.
3. Use overlap courses as references, not full linear watches.
4. Paid courses are still assets, even when deferred.
5. Use [REFRESHER] checkpoints before heavy clusters instead of rereading whole textbooks.
