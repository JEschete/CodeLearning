I'm skipping the installation of CodeLite and going straight to Visual Studio 2026. The reason is that Visual Studio is a more widely used IDE, and it has better support for C++ development. It also has a more modern interface and better debugging tools.

To install Visual Studio 2026, follow these steps:
1. Go to the Visual Studio website: https://visualstudio.microsoft.com/
2. Click on the "Download Visual Studio" button and select the edition you want to install (Community, Professional, or Enterprise).
3. Run the installer and follow the prompts to install Visual Studio. Make sure to select the "Desktop development with C++" workload during the installation process.
4. Once the installation is complete, launch Visual Studio and sign in with your Microsoft account (if prompted).
5. Create a new C++ project by selecting "Create a new project" from the start page, then choose "Console App" and click "Next".
6. Enter a name for your project and choose a location to save it, then click "Create".
7. You should now see the main Visual Studio interface with your new project open. You can start writing your C++ code in the main.cpp file that is created by default.
8. Alternatively, you can open an existing C++ project by selecting "Open a project or solution" from the start page and navigating to the location of your project files.
9. You can open a folder, and manually add the .cpp and .h files to the project by right-clicking on the project in the Solution Explorer and selecting "Add" -> "Existing Item...". Then navigate to the location of your files and select them to add them to the project.
10. You can also create new .cpp and .h files by right-clicking on the project in the Solution Explorer and selecting "Add" -> "New Item...". Then choose "C++ File (.cpp)" or "Header File (.h)" and give it a name.
