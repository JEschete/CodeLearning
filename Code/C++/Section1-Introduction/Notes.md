Modern C++ and the C++ Standard
-------------------------------------
Programming Language: 
- Source code - The code written by the programmer in a high-level language (C++) that is human-readable.
- High-level language - A programming language that is closer to human language and abstracts away the details of the computer's hardware.
- For Humans - Designed to be easy for humans to read and write, rather than for computers to execute directly.

Editor uses two types of files: 
- .cpp - C++ source file, contains the implementation of the program
- .h (or .hpp) - C++ header file, contains declarations of functions, classes, and variables
	- .h vs .hpp - .h is the traditional C-style header file, .hpp is the C++ style header file

Binary or other low-level representation
- Object code - The machine-readable code generated by the compiler from the source code. It is not human-readable and is specific to the target platform.
- For computers - Designed to be executed by the computer's hardware, rather than for humans to read or write.

Compiler - Translates from high-level language to low-level language (object code)
Linker - links together our code with other libraries
	- Creates executable file (.exe) or shared library (.dll, .so, .dylib)

Testing and Debugging - Finding and fixing errors in the code to ensure it works as intended.

The C++ Build Process
---------------------------------------
Source Code
- File1.cpp
- File2.cpp
- File3.cpp
- main.cpp

The above are passed through the compiler, which generates object files:
In windows they have the .obj extension, in linux they have the .o extension.

Object Code
- File1.obj
- File2.obj
- File3.obj
- main.obj

Then the linker takes these object files and links them together with any necessary libraries to create the final executable file.
These other libraries can be the C++ standard library, or other third-party libraries that provide additional functionality.

Integrated Development Environments (IDEs)
---------------------------------------
IDES are software applications that provide comprehensive facilities to computer programmers for software development. They typically consist of a source code editor, build automation tools, and a debugger.

- Editor
- Compiler
- Linker
- Debugger
- Keeps everything in sync

The IDEs used in the udemy course is CodeLite, but I'm going to use Visual Studio 2026
Main differences: 
- CodeLite is a lightweight IDE that is easy to set up and use, while Visual Studio is a more feature-rich IDE that provides advanced tools for debugging, profiling, and code analysis.
- CodeLite is cross-platform and can be used on Windows, Linux, and macOS, while Visual Studio is primarily designed for Windows development, although it does have a version for macOS.
