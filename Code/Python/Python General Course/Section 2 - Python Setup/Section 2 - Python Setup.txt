===========================================================================
Command Line Basics (Windows)
===========================================================================
Navigation:
    cd              - Reports the current directory path (Where am I?).
    dir             - Lists files and folders in the current directory.
    cd <folder>     - Moves into the specified folder.
    cd ..           - Moves up one level to the parent directory.
    <drive_letter>: - Switches drives (e.g., type "d:" and enter).

File Management:
    mkdir <name>    - Creates a new directory (folder).

Shortcuts:
    Tab             - Autocompletes folder/file names.
    Up/Down Arrows  - Cycles through command history.
    cls             - Clears the terminal screen.


===========================================================================
Virtual Environments (Windows)
===========================================================================

Definition:
    A self-contained directory that isolates Python libraries for a specific project.
    Why? To prevent version conflicts between different projects (e.g., Project A needs Library v1, Project B needs Library v2).

Commands:
    python -m venv <name>       - Creates a virtual environment (Standard names: .venv, venv).
    <name>\Scripts\activate     - Activates the environment (Command Prompt).
    .\<name>\Scripts\Activate   - Activates the environment (PowerShell).
    deactivate                  - Exits the virtual environment.

Accessing an existing environment:
    1. Navigate to your project folder: cd <project_folder>
    2. Run the activate command:        .venv\Scripts\activate
    (Your terminal prompt will show the environment name when active).
